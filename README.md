# 오후의 옷장

React + Vite + styled-components로 만든 조용한 옷 입히기 게임입니다. 별도 API 키, 백엔드, 외부 이미지나 폰트 없이 실행합니다. 모든 그래픽은 앱에 포함된 직접 제작한 SVG입니다.

## 실행

Node.js 20.19+ 또는 22.12+가 필요합니다. 검증 환경은 Node.js 24입니다.

```sh
npm ci
npm run dev
```

프로덕션 빌드와 로컬 확인:

```sh
npm run build
npm run preview
```

## 기능

- 내 방: 상의, 하의, 헤어, 소품을 클릭해 즉시 변경합니다.
- 코디: 이름을 붙여 최대 12개를 보관하고 다시 입거나 삭제합니다.
- 방 꾸미기: 벽지, 러그 색상과 화분 표시를 변경합니다.
- 오늘의 편지: 편지를 읽고 마음에 간직합니다.
- 다이어리: 제목, 내용, 기분과 현재 코디를 함께 기록하거나 삭제합니다.
- 이웃 산책: 샘플 이웃 세 명의 방을 보고 인사를 남깁니다. 실제 사용자 연결이나 메시지 전송 기능은 아닙니다.

데이터는 현재 브라우저의 localStorage(`afternoon-closet-v1`)에 저장됩니다. 다른 기기와 동기화되지 않으며 브라우저 데이터 삭제 시 사라집니다. 화면의 날씨는 게임 속 설정입니다.

## 구성

- `src/main.jsx`: 앱 화면, styled-components 스타일, SVG 방·인형·의상, 로컬 저장
- `index.html`: 한국어 문서 및 모바일 뷰포트 설정

390px 모바일, 768px 태블릿, 1440px 데스크톱 화면과 주요 기능은 Chromium에서 확인했습니다.

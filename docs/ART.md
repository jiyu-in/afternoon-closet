# 오후의 옷장 · 일러스트와 레이어 규격

## 현재 사용 중인 실제 에셋

참고 이미지의 갈색 잉크 선, 섬세한 눈과 머리카락, 차분한 채색, 옷의 주름과 봉제선 밀도를 관찰한 뒤 독창적인 성인 캐릭터와 실내를 이미지 생성·편집 도구로 제작했습니다. 참고 이미지의 인물, 교복, 포즈나 소품은 복제하지 않았습니다.

`public/art`의 PNG는 실제 게임에 연결된 일러스트입니다. 현재 화면에 임시 도형 캐릭터나 이모지 아이템은 없습니다. 러그의 직조선, UI 도구 아이콘, 광선과 작은 먼지는 목적에 맞는 SVG로 제작했습니다.

## 등록과 합성

- 기준 인형 좌표는 1024 × 1536. 머리 위쪽은 약 y=11, 발끝은 약 y=1508입니다. 모든 의상 PNG도 같은 크기로 보관합니다.
- 의상은 기본 인형을 참조하여 **사람 없이 옷만** 생성했습니다. 서로 다른 자세의 완성 캐릭터를 겹치지 않습니다.
- 생성물의 투명 여백과 의복 크기는 일정하지 않았으므로 `src/components/Avatar.jsx`의 `registration`에 파일별 크기·위치 보정을 명시했습니다. 출력은 항상 기준 인형 좌표계로 등록됩니다. 원본 이미지 픽셀 좌표가 이미 일치한다고 가정하지 마세요.
- 렌더 순서: 기본 몸·뒤쪽 머리 → 신발 → 하의 → 상의 또는 원피스 → 앞쪽 머리 → 가방 → 손. 원피스일 때 상·하의는 렌더하지 않습니다.
- 기본 복장 마스크로 원피스 아래 옆으로 삐져나오는 기본 옷을 지우고 팔은 복원합니다. 앞머리·손은 같은 기본 PNG의 클리핑 영역을 다시 사용합니다.
- 새 일러스트 교체 시 캔버스와 포즈를 유지하고, 등록 좌표 및 마스크를 함께 검토하세요. 봉제선과 목·손목·허리·신발 위치는 확대된 피팅 화면에서 확인해야 합니다.
- 독립 편집 요소는 벽 색, 러그, 화분이며 배경에 합쳐지지 않습니다. 옷장도 별도 이미지이며 클릭·키보드로 열립니다. 창가 벤치·책상은 배경의 고정 장식입니다.

## 현재 범위와 남은 한계

완성한 3세트는 블라우스+스커트, 로즈 원피스, 니트+팬츠입니다. 상·하의는 서로 조합할 수 있습니다. 헤어는 완성도 우선으로 갈색 기본 1종, 신발도 로퍼 1종입니다. 실제 눈 깜빡임이나 머리카락 물리 효과는 구현하지 않았으며, 빛·먼지·화분에만 작은 움직임을 넣었습니다. 설정과 OS의 reduced-motion을 지원합니다.

캐릭터는 정면 고정 자세의 종이인형이며 회전·다른 포즈는 지원하지 않습니다. 아트는 AI 제작 후 좌표·마스크를 보정한 게임용 일러스트이며 전문 원화가의 수작업 리깅을 대신한다고 주장하지 않습니다. PNG 원본을 포함하므로 최초 이미지 로딩 용량이 큽니다. 화면 크기에 맞는 추가 경량 이미지 변형은 향후 최적화 대상입니다.
